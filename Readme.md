Проект для получения данных валют

### Тесты ###

Тесты запускаются работая на текущей бд, используя контейнер

Для запуска контейнера использовать docker-compose.yaml в корне папки

### UPD

Тесты переведены на SQLite, нужда в контейнеризированном PostgreSQL отпала

Так же в репозитории хранятся ключи RSA, но они по сути пустышки, 
не для использования в production
